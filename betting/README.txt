LetBetAfrika – front-end prototype
==================================

Open index.html in any browser (Chrome, Safari, Edge). No server or install needed.
For the best demo, open it on a phone or use the browser's phone view.

Files
  index.html              page markup
  app.css                 all styles
  app.js                  app logic, demo matches/odds, betslip, wallet, settlement
  icons.js                team crests, flags, sport icons (SVG)
  games.js                games lobby artwork and Rocket Crash
  motion.js               splash screen and animations
  manifest.webmanifest    "Add to Home Screen" app settings
  img/                    banners, logo ball, favicon and app icons

Demo notes
  - Matches, odds, scores, accounts and money are simulated in the browser.
  - Log in with any 10-digit number to get a demo balance.
  - Country switch (Nigeria ₦ / Ghana GH₵) is in the menu, footer and Me page.
  - Splash plays once per browser session; add #splash=1 to the URL to replay it.

Still to build before real money: backend (sign-up with SMS, wallet, payments),
odds/data API, admin portal, licensed team logos, gaming licence.
