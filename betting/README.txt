LetBetAfrika – front-end prototype
==================================

Open index.html in any browser (Chrome, Safari, Edge). No server or install needed.
For the best demo, open it on a phone or use the browser's phone view.

Files
  index.html              page markup
  app.css                 all styles
  account.js              sign up, login, reset password, deposit and withdraw pages
  pages.js                live, sports filter, lists, jackpot, promos, results, Code Hub,
                          bet detail, Instant Football
  dark.css                dark theme (generated by tools/gen-dark.py)
  app.js                  app logic, demo matches/odds, betslip, wallet, settlement
  icons.js                team crests, flags, sport icons (SVG)
  game-logic.js           game rules, pay tables and exact return to player (shared with the server)
  games.js                games lobby artwork and Rocket Crash
  arcade.js               instant games: Lucky Dice, Spin & Win, Penalty Kick, Number Rush,
                          Keno, Scratch Cards, Hi-Lo
  motion.js               splash screen and animations
  manifest.webmanifest    "Add to Home Screen" app settings
  img/                    banners, logo ball, favicon and app icons

Demo notes
  - Matches, odds, scores, accounts and money are simulated in the browser.
  - Log in with any 10-digit number to get a demo balance.
  - Country switch (Nigeria ₦ / Ghana GH₵) is in the menu, footer and Me page.
  - Splash plays once per browser session; add #splash=1 to the URL to replay it.

Opened as a file this is a demo. Served by the API server (see ../HANDOVER.md) it runs on real
accounts, real odds and real money. Still needed before launch: payment, SMS and KYC providers,
licensed team logos, the gaming licence.

What's new
  - Sign up / login / forgot password are full pages with an SMS code step.
  - Deposit and Withdraw pages per country (card, bank transfer, OPay, PalmPay, USSD,
    mobile money, paybill, transfer to friend).
  - Live, Sports, Jackpot, Promotions, Results rebuilt on the reference layout;
    Code Hub (booking-code feed), bet ticket details, Instant Football.
  - Dark Mode on the Me page.
  - YOU WON trophy celebration on wins (Details / Show Off) with our own 3D-rendered LetBetAfrika
    trophy: gold cup engraved with the LB monogram, green LetBet|Afrika plinth, light burst.
  - Every game is playable: Rocket Crash, Virtual League, Instant Football, Weekly Jackpot, Lucky Dice,
    Spin & Win, Penalty Kick, Number Rush, Keno, Scratch Cards and Hi-Lo. Opened as a file they run in
    demo mode with the same pay tables; served by the API they play for real money.
  - When served by the API server everything above uses real accounts and money moves
    through the ledger; opened as a file it runs as a demo.
